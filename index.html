EEZ // DEMOSSPEC · NOT LIVE

Interactive explainers for the Ethereum Economic Zone

Each demo is a short, stepped walkthrough that pairs a plain-English explanation of one EEZ mechanic with verbatim code from the real source — the flow and the code, in the same frame. Play, step with ← / →, and watch the highlighted code follow the narration.

Contract layer: github.com/eez-association/eez-core-protocol @ main.
Infra layer: github.com/eez-association/eez-rollup0 @ main — the sequencer, composer, proof-signer, and deriver that actually run a chain.
Status: EEZ is pre-audit and not deployed; these show the design, not a live network.
Contributing: see CONTRIBUTING.md — internal team + core contributors, PR + review required.

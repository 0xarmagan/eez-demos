Dapp Developers — building a contract that makes or receives cross-chain calls
Compute your cross-chain address
2 min

Every (address, rollup) pair has one deterministic alias on every other chain — computable before anything is deployed.

address alias = eez.computeCrossChainProxyAddress(
    myContract,
    uint64(originRollupId)
);
// same inputs, same manager -> same output, always

Send a cross-chain call
3 min

You don't call a special function. Send a normal encoded call to the target's proxy address — the proxy's fallback forwards it.

bytes memory data = abi.encodeCall(
    IRemoteContract.setValue, (42)
);
(bool ok, ) = proxyAddress.call(data);
// destination sees this as a plain call

Fix the msg.sender gotcha
5 min

The destination sees the alias as msg.sender, never your real address. A same-chain owner check silently breaks.

// wrong: passes locally,
// reverts cross-chain
require(msg.sender == owner);

// right — whitelist the alias itself
address a = eez.computeCrossChainProxyAddress(owner, rid);
require(msg.sender == a);

Why you can't call the manager directly
2 min

Only a real proxy can trigger a cross-chain call. Calling the manager's entry point yourself reverts — this is the guard, not a bug.

// EEZ.sol — inside executeCrossChainCall
ProxyInfo storage proxyInfo = authorizedProxies[msg.sender];
if (!proxyInfo.isProxy) revert UnauthorizedProxy();
